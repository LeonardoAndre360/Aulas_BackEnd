# API de Gerenciamento de Livros (Assíncrona)

Esta é uma API construída com FastAPI para praticar os conceitos de concorrência e processamento assíncrono (async/await).

## Como rodar o projeto

1. Instale as dependências necessárias:
`pip install fastapi uvicorn`

2. Execute o servidor do FastAPI:
`uvicorn Tarefa2:app --reload` 

3. Acesse a documentação interativa para testar os endpoints:
Abra o navegador e acesse `http://127.0.0.1:8000/docs`
